# NeuroSem NMI figure redesign v2

This directory contains the code-first rebuild of the manuscript figures. The image-generation mockups are design references only; publication figures are generated by Python from frozen scientific values.

## Figure 1

Figure 1 is deliberately **fresh-clone reproducible**. The safe values required to draw it are committed under:

```text
paper/figure_data/nmi_redesign_v2/
```

Those committed snapshots are value-preserving exports of already-declared RunRelay source-data artifacts. `figure1_source_snapshot_manifest.json` records the exact source RunRelay job, exact source commit, artifact SHA-256 values, and the hashes of the original upstream derived outputs.

After pulling the repository:

```bash
.venv/bin/python scripts/paper/build_nmi_figure1_transfer_redesign_v2.py
.venv/bin/python scripts/paper/validate_nmi_figure1_transfer_redesign_v2.py
```

No private workstation `outputs/` directory is required to regenerate Figure 1.

Generated outputs:

```text
outputs/nmi_figure1_transfer_redesign_v2/latest/figure1.pdf
outputs/nmi_figure1_transfer_redesign_v2/latest/figure1.svg
outputs/nmi_figure1_transfer_redesign_v2/latest/figure1.png
```

The builder is presentation-only. It does not train or evaluate models and does not recompute the paper's scientific inference.

### Validation chain

The build/validation chain checks:

- expected participant counts (`n=17` ZuCo; `n=12` SMN4Lang);
- participant ordering and paired arithmetic (`neural-guided - text-only = delta`);
- the 17/17 and 12/12 primary sign results;
- primary mean effects and the already-frozen participant-bootstrap confidence intervals;
- all four optimization-run means and positive-participant counts;
- prospective versus post-confirmatory evidential status;
- SHA-256 hashes of the committed source snapshots, generated figure assets, builder, and copied source-data files;
- provenance links back to RunRelay job `4N8R2K7C` at exact commit `0ff001b37f17d91600035cab6c523676d3823d81` and to the original upstream output hashes.

For byte-level image comparisons, use the same repository commit, Python environment, Matplotlib version, and installed fonts. PDF/SVG/PNG bytes can differ across renderers or font installations even when the plotted scientific values are identical; the source-data tables and provenance manifests are the scientific reproducibility record.

### Design conventions

- ZuCo EEG is blue; SMN4Lang fMRI is orange.
- Participant-level primary transfer uses one x-position per participant, a baseline point at zero, the observed participant delta, and a directional arrow. This makes the paired displacement visible without letting between-participant baseline variation hide the small intervention effect.
- Half-violins are secondary density layers only and are used for `n=12/17` participant distributions, never for `n=3` added optimization runs.
- The marginal delta distributions show participant observations plus the already-reported participant-bootstrap 95% CI.
- Reliability panels show raw participant observations, a translucent density layer, and the arithmetic mean. They intentionally do not create a new reliability CI.
- Optimization-run consistency shows frozen run means and positive-participant counts only; it deliberately does not invent confidence intervals for added runs.
- The primary run is labeled `prospective primary`; added runs are labeled `post-confirmatory`. The figure does not use preregistration terminology.
