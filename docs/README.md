# Documentation map

The `docs/` directory contains both current submission records and historical protocol/result documents. Version dates and titles are intentional: older files preserve the analysis chronology and should not be read as the current manuscript state.

## Current submission records

- `5_CURRENT_ROADMAP.md`: current v1.18.1 publication state and stopping rules.
- `NMI_V118_PROVENANCE_LEDGER_SPEC.md`: current claim-to-artifact verification contract.
- `NMI_V118_DOCUMENT_MANIFEST_V1.json`: audited v1.18 document manifest retained as the scientific shipping record.
- `NMI_V118_FINAL_OVERLAY_V3.json`: final v1.18 provenance overlay used by the shipping audit.
- `30_NMI_FINAL_SPATIAL_VALIDATION_V1.md`: final spatial-validation protocol and interpretation.
- `NMI_ALTERNATIVE_SIGNAL_SURROGATE_V1.md`: structured non-neural surrogate protocol and interpretation.

## Historical records

`4_EXPERIMENT_LEDGER.md` is a chronological project log last updated before the final September provenance work. It remains useful for reconstructing the development history, but it is not the manuscript's accompanying numerical provenance ledger. Numerical claim verification is defined by `NMI_V118_PROVENANCE_LEDGER_SPEC.md` and produced by the final shipping audit.

Other numbered protocol and result documents retain the terminology and inferential status that applied when each analysis was frozen or completed. Later documents supersede them only where explicitly stated.
